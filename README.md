# 一键启动

一个 Windows 懒人启动器：自动扫描本地“开始菜单”和“桌面”中的应用，勾选需要启动的程序后一键批量启动。

## 运行

- 双击 `启动.bat`，或运行：

```powershell
python app.py
```

## 功能

- 自动扫描本地应用快捷方式
- 支持扫描 Steam 已安装游戏（读取 Steam 库和 appmanifest）
- 支持扫描微软商店 / UWP 应用（通过 Get-StartApps）
- 支持搜索过滤
- 勾选后一键启动多个应用
- 支持多个存档：新建、重命名、删除
- 新建存档默认不勾选任何应用
- 保存当前勾选到存档，并按不同存档一键启动
- 勾选变化自动保存到当前存档
